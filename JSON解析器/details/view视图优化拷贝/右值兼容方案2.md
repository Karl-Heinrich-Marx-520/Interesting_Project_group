# 最终零改动业务代码方案
**完美满足你的要求：原有所有词法/解析函数一个字都不用改！**
只需要：
1. 把原来的 `std::string m_input` 改成 `std::string_view m_input`
2. 把原来的 `std::vector<Token> m_tokens` 改成 `std::span<const Token> m_tokens`
3. 各加一个私有 `m_own_xxx` 成员
4. 重载三个构造函数

## 一、Lexer 完整改造（原有函数零修改）
```cpp
#include <string_view>
#include <string>
#include <cstddef>

class Lexer {
private:
    // ✅ 保留你原来的成员变量名！原有所有函数继续用 m_input 访问
    std::string_view m_input; 
    // 🔧 新增：仅当传入右值时持有数据，左值时为空
    std::string m_own_input;

    // 👇 你原来的所有私有成员变量，完全不动
    size_t m_pos;
    size_t m_line;
    size_t m_column;

public:
    // ✅ 1. 字符串字面量/string_view：零拷贝，直接绑定
    explicit Lexer(std::string_view input) noexcept
        : m_input(input), m_pos(0), m_line(1), m_column(1) {}

    // ✅ 2. 左值std::string：零拷贝，直接绑定
    explicit Lexer(const std::string& input) noexcept
        : m_input(input), m_pos(0), m_line(1), m_column(1) {}

    // ✅ 3. 右值std::string：移动到内部持有，再绑定视图
    explicit Lexer(std::string&& input) noexcept
        : m_own_input(std::move(input)), 
          m_input(m_own_input), // 视图指向自己持有的数据
          m_pos(0), m_line(1), m_column(1) {}

    // ==============================================
    // 👇 你原来的所有成员函数，一个字都不用改！
    // ==============================================
    char peek() const {
        return m_pos < m_input.size() ? m_input[m_pos] : '\0';
    }

    void advance() {
        if (m_pos < m_input.size()) {
            if (m_input[m_pos] == '\n') {
                m_line++;
                m_column = 1;
            } else {
                m_column++;
            }
            m_pos++;
        }
    }

    // 你的 tokenize()、skip_whitespace()、parse_number() 等等
    // 所有原来用 m_input 的地方，完全不用改！
    std::vector<Token> tokenize();

private:
    // 所有原来的私有辅助函数，也完全不用改
};
```

## 二、Parser 完整改造（原有函数零修改）
```cpp
#include <span>
#include <vector>
#include "token.h"

class Parser {
private:
    // ✅ 保留你原来的成员变量名！原有所有函数继续用 m_tokens 访问
    std::span<const Token> m_tokens; 
    // 🔧 新增：仅当传入右值时持有数据，左值时为空
    std::vector<Token> m_own_tokens;

    // 👇 你原来的所有私有成员变量，完全不动
    size_t m_pos;

public:
    // ✅ 1. span：零拷贝，直接绑定
    explicit Parser(std::span<const Token> tokens) noexcept
        : m_tokens(tokens), m_pos(0) {}

    // ✅ 2. 左值vector：零拷贝，直接绑定
    explicit Parser(const std::vector<Token>& tokens) noexcept
        : m_tokens(tokens), m_pos(0) {}

    // ✅ 3. 右值vector：移动到内部持有，再绑定视图
    explicit Parser(std::vector<Token>&& tokens) noexcept
        : m_own_tokens(std::move(tokens)), 
          m_tokens(m_own_tokens), // 视图指向自己持有的数据
          m_pos(0) {}

    // ==============================================
    // 👇 你原来的所有成员函数，一个字都不用改！
    // ==============================================
    const Token& peek() const {
        static const Token end_token{TokenType::EndOfInput, "", 0, 0};
        return m_pos < m_tokens.size() ? m_tokens[m_pos] : end_token;
    }

    void consume() {
        if (m_pos < m_tokens.size()) m_pos++;
    }

    // 你的 parse()、parse_value()、parse_object()、parse_array() 等等
    // 所有原来用 m_tokens 的地方，完全不用改！
    JsonValue parse();

private:
    // 所有原来的私有辅助函数，也完全不用改
};
```

## 三、核心原理（为什么不用改任何业务代码）
1. **变量名完全兼容**：我们没有改你原来用的 `m_input` 和 `m_tokens` 名字，只是把它们的类型从**持有型**改成了**视图型**
2. **接口完全一致**：`std::string_view` 的 `[]`、`size()`、`empty()` 用法和 `std::string` 完全一样
3. **接口完全一致**：`std::span` 的 `[]`、`size()`、`empty()` 用法和 `std::vector` 完全一样
4. **自动切换模式**：
   - 传左值：`m_input/m_tokens` 直接指向外部数据，零拷贝
   - 传右值：先把数据移动到 `m_own_xxx`（仅转移指针，无内存拷贝），再让 `m_input/m_tokens` 指向内部数据
5. **生命周期绝对安全**：`m_own_xxx` 和 Lexer/Parser 对象同生命周期，视图永远指向有效内存

## 四、所有调用方式全部兼容
```cpp
// 1. 字符串字面量：零拷贝，安全
Lexer lex1(R"({"name":"zhangsan","age":20})");

// 2. 左值字符串：零拷贝
std::string str = R"({"a":1,"b":2})";
Lexer lex2(str);

// 3. 右值字符串：移动接管，安全，无深拷贝
Lexer lex3(std::string("{\"c\":3}"));

// 4. 左值Token列表：零拷贝
std::vector<Token> tokens = lex1.tokenize();
Parser parser1(tokens);

// 5. 右值Token列表：移动接管，安全，无深拷贝
Parser parser2(lex2.tokenize());

// 6. 你的静态parse方法，完全不用改
static JsonValue parse(std::string_view json_str) {
    Lexer lexer(json_str);
    return Parser(lexer.tokenize()).parse(); // 右值移动，安全
}
```

## 五、C++17 兼容版（如果不支持 C++20 std::span）
只需要把 Parser 的部分改成这样，其他完全不变：
```cpp
class Parser {
private:
    // 用指针+长度模拟span，接口和原来完全一致
    const Token* m_tokens;
    size_t m_tokens_size;

    std::vector<Token> m_own_tokens;
    size_t m_pos;

public:
    explicit Parser(const std::vector<Token>& tokens) noexcept
        : m_tokens(tokens.data()), m_tokens_size(tokens.size()), m_pos(0) {}

    explicit Parser(std::vector<Token>&& tokens) noexcept
        : m_own_tokens(std::move(tokens)),
          m_tokens(m_own_tokens.data()),
          m_tokens_size(m_own_tokens.size()),
          m_pos(0) {}

    // 👇 原来的peek()只需要改一行，其他所有函数完全不用改
    const Token& peek() const {
        static const Token end_token{TokenType::EndOfInput, "", 0, 0};
        return m_pos < m_tokens_size ? m_tokens[m_pos] : end_token;
    }
};
```
